NYISO predictions are assumed to be generated by 5:00 a.m. Eastern Time on the day before delivery. For each target day, the latest archived load-forecast vintage available by that cutoff is used. Same-day actual load and forecasts issued after the cutoff are excluded from model inputs.
NYISO predictions are generated as of 5:00 a.m. Eastern Time on the day before delivery. Each target hour uses the latest archived Hudson Valley load forecast available by that cutoff. When an exact publication timestamp is unavailable, availability is conservatively reconstructed from the NYISO publication schedule and clearly identified as assumed. Actual target-hour load is excluded from model predictors.
